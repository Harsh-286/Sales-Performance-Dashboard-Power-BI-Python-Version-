# Sales-Performance-Dashboard-Power-BI-Python-Version-
In this project, I built an interactive Sales Performance Dashboard using Power BI.
First, I cleaned and transformed raw data using Power Query and Pandas.
Then I created KPIs such as total revenue, profit margin, and regional performance.
I used filters, drill-down charts, and time-series visuals to make the dashboard interactive.
The dashboard helped identify top-performing products and underperforming regions.”
